# El Despertar del Héroe

Juego por turnos, tienes que liberar las almas secuestradas por Vesperos

## Requisitos
- JDK: 26.0.2.1
- IDE: Visual Studio Code

## Cómo compilar y ejecutar
1. Abre una terminal en la carpeta del proyecto
2. Compila el código:
    `´
    javac Juego.java
    `´
3. Ejecuta el Juego:
    `´
    java Juego
    `´
## Reglas del juego
Juego por turnos: primero ataca el jugador.
Puedes atacar, curarte o abandonar el combate.
Tienes 3 pociones que te curarán 25 de vida cada una; la vida máxima es de 100
El héroe hara entre 10 y 20 de daño; los enemigos entre 5 y 15
